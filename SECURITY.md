# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential.
Use GitHub's **Security → Report a vulnerability** form so the report remains private.

Include the affected version, impact, reproduction steps, and any proposed mitigation. Do not
include real Telegram tokens, Strava credentials, activity files, or location history.

Security fixes are provided for the latest released version. No response-time guarantee is made
while the project is maintained by volunteers.
